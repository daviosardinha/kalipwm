# V1 install flow

```text
bash kalipwm.sh
  -> install.sh
  -> pre-flight
  -> detect environment
  -> confirm/override environment
  -> discover hardware
  -> confirm display preference
  -> show detection summary
  -> user approval
  -> backup managed configuration
  -> install common + environment packages
  -> install fonts
  -> configure ZSH/tmux
  -> copy desktop configuration and helpers
  -> write profile.conf
  -> logout / choose BSPWM
```
