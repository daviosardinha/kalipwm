# Obsidian Tactical visual rules

V1 aims for a professional operator workstation rather than a neon/rainbow hacker theme.

- base canvas: near-black charcoal
- window surfaces: graphite
- normal text: soft gray/white
- primary interaction accent: restrained violet
- healthy/connected: muted green
- attention: muted amber
- target/critical/disconnected: muted red
- Picom corners: 9px
- BSPWM gap: 9px
- focused border: 2px violet
- Kitty opacity: 0.94
- Rofi: centered search-first launcher
- Polybar: thin full-width operational status bar

Color should communicate state. Red is not a general decoration color.
